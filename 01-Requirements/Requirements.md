# E-Commerce Web Application - Requirements

## 1. Project Overview

This project focuses on testing the functionality of an e-commerce web application through manual testing.

## 2. Objective

The objective is to verify that the application functions according to the defined requirements and provides the expected results to users.

## 3. Modules

The following modules are included in the testing scope:

1. User Registration
2. User Login
3. Product Search
4. Product Details
5. Shopping Cart
6. Checkout
7. Logout

## 4. Functional Requirements

### FR-001: User Registration

The application should allow new users to create an account using valid information.

### FR-002: User Login

The application should allow registered users to log in using valid credentials.

### FR-003: Product Search

The application should allow users to search for products using relevant keywords.

### FR-004: Product Details

The application should display the selected product's details correctly.

### FR-005: Shopping Cart

The application should allow users to add, update and remove products from the shopping cart.

### FR-006: Checkout

The application should allow users to proceed through the checkout process after adding products to the cart.

### FR-007: Logout

The application should allow logged-in users to securely log out.

## 5. Non-Functional Requirements

- Application should be easy to use.
- Web pages should load correctly.
- User interface should be consistent.
- Application should work correctly on supported browsers.

## 6. Testing Scope

### In Scope

- Functional testing
- UI testing
- Smoke testing
- Sanity testing
- Regression testing
- Retesting
- Positive testing
- Negative testing
- Black-box testing

### Out of Scope

- Performance testing
- Security penetration testing
- Backend server testing
- Payment gateway server testing

## 7. Test Environment

**Operating System:** Windows

**Browser:** Google Chrome

**Testing Type:** Manual Testing
